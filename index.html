Multi-Device-Sync

Ohne Konfiguration bleiben die Daten lokal auf diesem Gerät (dauerhaft gespeichert, überlebt Tab-Schließen & Neustart). Für Live-Bearbeitung von mehreren Geräten: kostenloses Supabase-Projekt anlegen (Anleitung unten) und hier eintragen. Sync-Modell: Revision + Compare-and-Swap, Polling alle 8 s, Sofort-Push nach eigener Änderung.
Status: nicht konfiguriert.
📖 Anleitung: Supabase in 10 Minuten (kostenlos)
  1. supabase.com → Konto anlegen → „New project“ (Region EU, Free Plan).
  2. Links SQL Editor öffnen und dieses Snippet ausführen:
create table daily_states (
  room_id text primary key,
  payload jsonb not null,
  revision integer not null default 0,
  updated_at timestamptz not null default now(),
  updated_by text not null
);
alter table daily_states enable row level security;
create policy "cockpit_rw" on daily_states
  for all using (true) with check (true);
  1. Project Settings → API: „Project URL“ und „anon public“-Key kopieren, oben eintragen.
  2. Room-ID generieren (zufällig, ≥128 Bit — sie ist dein Schlüssel), „Verbinden“ drücken.
  3. Auf dem zweiten Gerät (z. B. iPhone): dieselbe Datei öffnen (gehostet, z. B. GitHub Pages) und URL/Key/Room identisch eintragen — fertig, Häkchen erscheinen live auf beiden Geräten.
🔐 Wer Anon-Key + Room-ID kennt, kann mitschreiben. Keine Passwörter/Kundendaten in Aufgaben speichern. Zugangsdaten liegen nur lokal in deinem Browser.
